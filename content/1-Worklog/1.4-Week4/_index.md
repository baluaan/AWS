### Week 4 Objectives:

- Master Enterprise File Systems & Cross-Region Storage: Deploy Multi-AZ Amazon FSX for Windows File Server (SSD/HDD), enable data deduplication, and configure Amazon S3 Cross-Region Replication (CRR) alongside static hosting and security policies.

- Implement Cloud Security Posture Management: Gain hands-on experience with AWS Security Hub to assess, monitor, and evaluate security posture against industry standards and compliance benchmarks.

- Automate Cost Optimization & Resource Governance: Leverage AWS Lambda and resource tagging strategies to automate EC2 lifecycle management and reduce operational costs.

- Streamline AWS Resource Organization: Establish resource tagging strategies and build Resource Groups for efficient monitoring, bulk management, and cloud governance.

### Week 4 Achievements:

- Successfully Deployed Amazon FSX for Windows File Server: Provisioned Multi-AZ SSD and HDD file systems, configured file shares, monitored system performance, and enabled data deduplication for optimal storage efficiency.

- Advanced Amazon S3 Management & Cross-Region Replication: Configured static web hosting with public access block rules, and successfully set up Multi-Region S3 Object Replication for high availability and disaster recovery.

- Operationalized AWS Security Hub: Enabled Security Hub across the environment, reviewed standard-based security scores, and performed security assessments before performing proper resource cleanups.

- Automated EC2 Cost Optimization via AWS Lambda: Created custom resource tags, configured IAM execution roles, and deployed AWS Lambda functions to automatically start/stop non-production EC2 instances based on schedules or tags.

- Implemented AWS Resource Governance: Established consistent tagging practices and created AWS Resource Groups to streamline resource management and governance across cloud infrastructure.
