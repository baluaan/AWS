### Week 1 Objectives:

- Get familiar with the internship environment and gain a high-level overview of AWS Cloud Architecture & Global Infrastructure.
- Successfully register and secure a hands-on AWS account (Enable MFA, configure IAM Admin Group/User/Roles).
- Manage cloud costs by configuring various AWS Budgets and acquiring practice credits (achieving 180/200 credits from guides).
- Explore AWS Support Plans and master the process of submitting technical support tickets.
- Learn standard conventions for drawing AWS architecture diagrams.

### Key Achievements in Week 1:

- Gained a clear understanding of the learning roadmap, AWS fundamental concepts, and architectural diagramming standards.
- Successfully set up a secure AWS practice account with MFA enabled and redeemed 180/200 AWS credits.
- Mastered basic IAM access control: Created Admin Groups/Users, configured IAM Roles, and applied the Principle of Least Privilege.
- Implemented comprehensive AWS Budgets alerts to prevent unexpected charges.
- Understood how to leverage AWS Support Center for technical inquiries and service quota requests.
