### Objective

Configure and operate the **Amazon CloudWatch Agent** on an Ubuntu EC2 instance to collect, format, and automatically push system logs (`/var/log/auth.log`) to a **CloudWatch Logs Group**, establishing the data foundation for analysis and automated response steps.

---

## 1. Overview

The Log Collection Layer acts as the starting link for the entire automated incident response process. In this architecture, the **Amazon CloudWatch Agent** serves as a data collector (Daemon/Agent) running in the background on the Ubuntu EC2 instance, directly monitoring changes to the system log file `/var/log/auth.log`.

Configuring the CloudWatch Agent provides critical benefits:
- **Real-time Streaming:** Automatically pushes log lines generated by the SSH service (`sshd`) to the AWS CloudWatch Logs service with extremely low latency.
- **Centralized Log Management:** Aggregates all access events and failed login attempts from the server into the **CloudWatch Log Group** `/aws/ec2/security/auth`, facilitating querying, filtering information, and setting up **Subscription Filters** and **Metric filters**.
- **Separation of Concerns:** Ensures log data is safely retained in the cloud even if the EC2 instance is interrupted or attacked externally.
